# zai_python_helper

> MIT-лицензированный, **clean-room** Python-хелпер, который подключает **Claude Code**
> к тарифному плану **Z.ai GLM Coding Plan**, правя конфигурационные файлы — без фонового
> сервиса, без бинарника. Спроектирован **импортируемым** (планирующее ядро — библиотека)
> и **headless** (каждое действие — флаг CLI).

## Что это

`zai-python-helper` переправляет Claude Code (и другие кодинг-агенты) на эндпоинт
[Z.ai](https://z.ai) GLM Coding Plan, редактируя за вас три файла:

- `~/.claude/settings.json` — модель и base URL, которые читает Claude Code
- `~/.claude.json` — внутреннее состояние Claude Code
- `~/.zshrc` — переменные окружения оболочки (внутри собственного, обрамлённого
  маркерами блока — ваши строки никогда не удаляются, см. [Архитектура → ADR-003](../ARCHITECTURE.md))

Это **не** прокси, **не** демон и **не** форк проприетарного `@z_ai/coding-helper`
(npm) от Z.ai. Это независимая реимплементация, повторяющая *наблюдаемое поведение*
того инструмента — написанная с нуля и выпущенная под MIT. См. [Parity](parity.md):
что клонировано байт-в-байт, а что — наше расширение.

## Зачем

- **Без демона.** Одноразовый CLI. Запусти, заверши, забудь.
- **Обратимо.** [Журнал владения](../ARCHITECTURE.md) записывает предыдущее
  значение каждого ключа до того, как мы его коснёмся, поэтому `use default`
  восстанавливает ровно то, что было — и отказывается затирать ключ, изменённый
  снаружи.
- **Атомарно.** Многофайловый `PatchPlan` валидируется, затем применяется под
  процессным локом с атомарными переименованиями (ADR-005). Два параллельных
  вызова `use` сериализуются; прерванный запуск докатывается при следующем.
- **Импортируемо.** Планирующее ядро (`plan_zai`, `plan_default`,
  `postconditions`) и доменные типы (`ProviderSpec`, `ModelMode`, `Region`) —
  чистые функции, которые можно вызывать из своего Python. Публичная поверхность
  — версионный контракт [`__all__`](../api/zai_python_helper.md).

## Установка за 30 секунд

```bash
pip install zai-python-helper
```

Затем переключите Claude Code на Z.ai:

```bash
# Режим 1 (original): только ANTHROPIC_BASE_URL → Z.ai, модель выбирает сервер
zai-python-helper use zai

# Передайте auth-токен Z.ai (или экспортируйте ZAI_API_KEY)
zai-python-helper use zai --api-key "$ZAI_API_KEY"
```

Вернуться к конфигурации Anthropic по умолчанию:

```bash
zai-python-helper use default
```

Наблюдаемость и диагностика только для чтения:

```bash
zai-python-helper status    # что сейчас активно, где и какие пути разрешены
zai-python-helper doctor    # полная диагностика интеграции
zai-python-helper list      # доступные пресеты моделей Z.ai
```

!!! tip "Нужна библиотека, а не CLI?"
    Всё, что делает CLI, можно сделать в процессе. См.
    [Импортируемое API → гайд](guide/importable.md).
